## 🚀 Como Usar

### 1. Executar Localmente
```bash
npm run dev
# Acesse http://localhost:3000
```

### 2. Fazer Build
```bash
npm run build
```

### 3. Usar as Cores
```tsx
<div className="bg-divus-blue text-divus-yellow">
  Conteúdo
</div>
```

### 4. Usar as Fontes
```tsx
<h1 className="font-jakarta text-4xl font-bold">Título</h1>
<h2 className="font-instrument text-2xl">Subtítulo</h2>
```
